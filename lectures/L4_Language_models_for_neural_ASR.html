Prefix beam search keeps the best partial transcripts

State

A set of prefixes, each with the probability of ending in a blank or in a label.

Step

Extend every prefix with every label, merge prefixes that collapse to the same text.

Prune

Keep the B best prefixes: beam width B is a speed–accuracy knob.

Without an LM, beam search alone gains little over greedy on CTC: the gain comes from rescoring words.

ARPA file

Practical traps

Dependencies

pip install pyctcdecode downgrades numpy: install it with --no-deps.

Case

LibriSpeech ARPA files are upper case; wav2vec2 labels here are lower case.

Vocabulary

Words absent from the LM are penalised: watch names and numbers.

Over-weighting

Large α makes fluent but wrong text, as on day 1.
