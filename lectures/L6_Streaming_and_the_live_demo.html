How the demo works

Record button

Hold Space or click: no silence detection needed; release = end of utterance.

Backend per recording

Pick any registered backend from the list for each new recording.

L6 · Streaming and the live demo · 24 Nov

Run the server on the student's laptop: browsers only give microphone access on localhost or HTTPS.

The contract: two methods

class Backend: new_session() → Session
class Session: accept_chunk(audio) → partial text or None
finish() → final text

Offline model

Subclass OfflineBackend and implement transcribe(audio). Optional re-decoding for live partials.

Streaming model

Return your own Session that keeps state between chunks.

Timing

Measured by the server, identically for every backend.

Practicalities

Microphone

localhost or HTTPS only; the browser resamples to 16 kHz.

First use

A backend loads on first selection: count load time separately.

CPU threads

Close other heavy programs; compare backends in the same conditions.

Not graded

The demo tests the practical value of your decision, not your grade.
